# Applying these standards to existing guides

These standards were written to match the structure already used in the Guides set:

- Audience + Scope at the top
- Clear headings and skimmable sections
- Evidence-backed behavior claims where applicable

You do not need to rewrite existing guides to “comply” perfectly. Use this kit primarily for:
- new pages
- major edits
- PR reviews

If you update an existing guide, prioritize:
1. keeping claims scoped and verifiable
2. keeping examples consistent
3. adding verification steps where missing
