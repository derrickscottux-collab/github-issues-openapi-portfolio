# v2.0 verification checklist (documentation set)

## Build checks
- [ ] `node scripts/build-guides.mjs` completes with exit code 0.
- [ ] `docs/guides/index.html` exists after build.
- [ ] `docs/guides/guides.css` exists after build.
- [ ] Each guide has a corresponding HTML page in `docs/guides/`:
  - [ ] `quickstart.html`
  - [ ] `pagination-and-filters.html`
  - [ ] `errors-and-troubleshooting.html`
  - [ ] `support-checklist.html`
  - [ ] `glossary.html`

## Navigation checks
- [ ] From `docs/guides/index.html`, each guide button opens the expected `.html` page.
- [ ] Each guide page links back to `index.html` (Guides home).
- [ ] Headings render as headings (no visible leading `#` characters).

## Link correctness checks
- [ ] No “Related links” open local disk paths (for example `C:\` or `/Users/...`).
- [ ] “Related links” open canonical GitHub URLs (`tree/main/...` or `blob/main/...`).
- [ ] Repo README contains both:
  - [ ] Guides live HTML URL
  - [ ] Guides source Markdown links
- [ ] OpenAPI `externalDocs` points to the Guides index URL.

## Deployment smoke test (Pages)
- [ ] Open API reference docs on Pages and confirm it loads.
- [ ] Open Guides index on Pages and confirm it loads.
- [ ] Open at least 2 guide pages and click 3 related links each.
